<h1 align="center">MetroBilbao</h1>

<p align="center">
Una app informativa sobre el Metro de Bilbao
</p>

<hr/>

<h2>📌 Descripción del proyecto</h2>

<p>
MetroBilbao es una aplicación nativa de Android escrita en Java que ofrece toda la información necesaria para navegar por las lineas de metro de Bilbao fácilmente. Desde planificar tu viaje, ver las noticias relevantes o hasta simplemente mirar como los trenes se mueven por el mapa.</p>

<p>La aplicación aún esta en desarrollo y esperando mejoras, los datos no son precisos en tiempo real debido a la falta de rastreadores en los trenes, pero la estimación está basada en los horarios oficiales de Metro Bilbao. Aplicación hecha como proyecto personal.</p>

---

<h2>🛠️ Características principales</h2>

<ul>
  <li>Java, XML y Kotlin</li>
  <li>Información en tiempo real sobre la posición de trenes, como llegar a ciertos sitios, los precios y las noticias</li>
  <li>Diseño moderno y acorde a una estructura más accesible para las nuevas generaciones</li>
</ul>
